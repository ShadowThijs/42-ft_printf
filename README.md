# ft_printf

This project has been created as part of the 42 curriculum by tlogtenb.

## Description

A copy of printf.

## Instructions

Compile with `make`.
Create your program and add `#include "ft_printf.h"`.
Build with `gcc -Wall -Werror -Wextra main.c libftprintf.a -o main`.

Usage of function:
- `ft_printf("%s", string);`: Print a string
- `ft_printf("%p", pointer);`: Print a pointer
- `ft_printf("%x", hex);`: Print lower case hex number
- `ft_printf("%X", HEX);`: Print upper case hex number
- `ft_printf("%i", integer);`: Print an integer
- `ft_printf("%d", number);`: Print a number
